Support

Start here when something does not behave as expected.

Content is missing

Check the active filters, return to Ideas or Content, and clear the filters. Relaunching the app reloads the local library.

Share extension is missing

Open More in the system share sheet and enable JotSprout. The extension and main app use the same local library.

Recognition is inaccurate

Image text recognition and voice transcription are assistive. Open the attachment details and edit recognized text; the original file remains available.

Moving to another device

Export a complete backup from Settings, keep it in Files or another safe location, then choose Restore on the new device. Complete backups include attachments.

Export a complete backup before troubleshooting. Do not include private notes, images or recordings in a report.

When reporting an issue

  • Device model and operating system version
  • JotSprout version
  • The page and steps that led to the issue
  • Whether the issue can be reproduced
